# FrameMaker Automation Notes

## Objective

Reduce unresolved text inset errors in large multilingual FrameMaker books.

## Current Approach

- Parse Book Error Logs
- Extract unresolved inset paths
- Match by basename
- Generate repair plan
- Execute relinking with JSX

## Long-Term Goals

- Cross-reference repair
- Image-path repair
- Global refresh automation
- Translation-aware workflows
